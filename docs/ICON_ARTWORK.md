# Anteater application icon

Created with the built-in imagegen tool for this project. Final PNG artwork:
`assets/editor.png`; Windows multi-resolution conversion: `assets/editor.ico`.
The ICO includes 16, 24, 32, 48, 64, 128 and 256 pixel images, with transparency.
It is used for the running app, installer and installed shortcuts.

Generation prompt: A polished Windows application icon depicting a giant
anteater in side profile, with a very long narrow downward snout, small ears,
diagonal black-and-white shoulder stripe and huge bushy tail. Natural grey,
black and cream colors, compact illustrated mascot, clean silhouette and
readability on light and dark Windows taskbars. Square canvas, centered animal,
transparent background; no lettering, border, car or other objects.
