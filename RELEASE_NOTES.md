# BMW DDE5 MS43 Tuner 1.34.0 — Windows x64

77.2% generated by AI (author-provided estimate).

Run **BMW_DDE5_MS43_Tuner_1.34.0_Setup.exe**. Setup downloads private Python
from python.org and verified runtime libraries from PyPI. Internet is required.
It installs for the current Windows user, adds a Start menu shortcut, offers a
desktop shortcut and registers an uninstaller in Installed apps. System Python
is unchanged. The installer is unsigned.

- Add, remove and reorder bottom gauges while live logging runs. A pinned
  **+ Add gauge** button and direct **×** controls stay accessible.
- Adding a gauge or opening a table that needs an available but uncollected
  channel asks for confirmation before extending the logging selection.
  **Logging channels…** also changes the active acquisition selection.
- Direct serial DDE5, native EDIABAS, TestO and MS43X apply channel changes
  between ECU replies without reconnecting. Removing a gauge changes only
  the display; it does not silently stop collecting that channel.
- DDE5 previews the realtime block count and warns before another block slows
  logging. Each block holds up to ten values, including repeated RPM and
  injection-quantity anchors.
- Changes to a captured selection continue in a new `.partN.csv` segment with
  its own fixed header and metadata. Existing files are retained; elapsed
  timestamps keep the session's original time origin. Open each segment
  individually for recorded review.
- Automatic table-position tracing now covers 459 of 863 bundled MS43X
  multi-cell tables and 46 of 103 DDE5 multi-cell tables. Reference axes and
  constants have no runtime lookup position. Quantities unavailable from the
  logging definitions remain explicitly unbound and may need verified manual
  axis bindings.
- Vertical one-dimensional curves, pressure/time unit conversions and sparse
  DDE5 coordinates work in live and recorded review. A sparse coordinate can
  hold its most recent earlier reading for at most one second; future samples
  are never borrowed. VE table traces exclude unknown or fractional selections.
- Clearer live status, block budget and missing-channel actions accompany the
  updated gauge layout. Gauge geometry work is reduced and expensive graph
  redraws are limited by elapsed time while acquisition retains every reply.
- Verified DDE5 serial definitions now accept LF and CRLF checkouts without
  weakening the pinned scaling integrity check.

Existing calibration addresses, channel IDs, ECU-specific settings and profiles
are retained. MS43X001 full/64 KB XDFs and the logging ADX remain included under
their upstream GPL-3.0 licence. The current 361830 definition and eight generated
ECU library XDFs are included.

No Python runtime, library wheels/DLLs, firmware images, raw map packs or
disassembly dumps are embedded. The small OLS import helper is included under
0BSD, with its source and licence. Runtime and dependency hashes are pinned.

Validation uses synthetic calibration data, simulated diagnostic traffic and
GUI checks. In the Linux workspace, 646 tests passed and 57 optional tests were
skipped; five existing failures involved restricted localhost sockets or a
Windows-only account-lock expectation. Startup and public self-checks passed.
The new behavior has not been validated with a physical ECU. Windows CI must
pass its required checks before the installer is released.

See [live-channel and tracing details](docs/TRACING_AND_LIVE_CHANNELS.md) and
the README for installation and first-use instructions.
