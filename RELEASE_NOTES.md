# BMW DDE5 MS43 Tuner 1.34.0 — Windows x64

77.2% generated by AI (author-provided estimate).

## Changes

- Add, remove and reorder gauges while live logging runs, with a pinned
  **+ Add gauge** button and direct remove controls.
- Confirm additions to logging when a gauge or table needs a missing parameter.
  **Logging channels…** can also change the active acquisition selection.
- DDE5 shows the realtime block cost and warns before another block slows
  logging. Each block holds up to ten values, including repeated RPM and
  injection-quantity anchors.
- Expanded live and recorded table tracing: automatic positions for 459 bundled
  MS43X tables and 46 DDE5 tables, including vertical curves, unit conversions,
  bounded past-only coordinates between DDE5 request groups and exact VE-table
  selection rules.
- Clearer live status, block budget and tracing actions, plus less gauge layout
  work and fewer expensive graph redraws.
- DDE5 serial scaling verification now accepts LF and CRLF checkouts without
  weakening its pinned integrity check.

Accepted channel changes apply between ECU replies without reconnecting. Removing
one gauge changes only the display. A change to the captured selection continues
in a separate `.partN.csv` file with its own header and metadata; existing files
are kept. Open each segment individually for recorded review.

[Full changelog](https://github.com/tuned-by-emil/BMW_DDE5_MS43_tuner/blob/v1.34.0/CHANGELOG.md)

## Install

Download **BMW_DDE5_MS43_Tuner_1.34.0_Setup.exe** and its matching `.sha256` file,
then run the installer. Setup downloads private Python and hash-verified runtime
libraries from python.org and PyPI. Internet is required. Installation is for the
current Windows user, with a Start menu shortcut, optional desktop shortcut and
uninstaller. System Python is unchanged. The installer is unsigned.

## Validation and limits

Tables requiring quantities the logging definitions do not expose remain
explicitly unbound. Constants and reference axes have no runtime lookup position.
Existing calibration addresses, channel IDs, ECU-specific settings and profiles
are retained.

The changes use synthetic calibration data, simulated diagnostic traffic and GUI
checks; they have not yet been validated with a physical ECU. Linux workspace
validation passed 646 tests, with 57 optional skips and five existing failures
involving restricted localhost sockets or a Windows-only account-lock expectation.
Startup and public self-checks passed. Windows CI must pass its required checks
before the installer is released.
