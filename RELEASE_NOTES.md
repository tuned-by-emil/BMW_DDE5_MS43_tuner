# BMW DDE5 MS43 Tuner 1.35.0 — Windows x64

77.2% generated by AI (author-provided estimate).

## Changes

- **ECU > DDE5 patch checks** verifies the supported ECU identity, installed MPC
  admission words and selected runtime state. Separate actions check the baud
  round trip or four explicitly reserved RAM bytes, with restoration reports.
- **ECU > DDE5 RAM calibration bench** plans complete firmware-block allocations,
  compares the live flash baseline, checks both allocator pools and exercises
  native copy/page selection. Its optional changed-byte probe restores and
  verifies the original value before returning to the reference page.
- **ECU > DDE5 live RAM editing** unlocks only after that open connection passes
  an actual reversible write, exact mapped readback, byte restoration and
  verified reference-page restoration. Saved reports cannot unlock a connection.
- After qualification, upload selected table values and editable axes, read RAM
  back into the editor as an undoable change, restore selected values from the
  original BIN, and select the reference or working page. Uploads verify previous
  and changed bytes through native one-byte mapped checksums.
- Whole-block capacity checks include the 1,116-byte directory and both allocator
  pools. Existing RAM edits in shared blocks are preserved when another table is
  registered. Multi-cell uploads are sequential and are not atomic.
- Communication failures lock live controls and stop further commands. Healthy
  failures attempt verified rollback and reference-page restoration; uncertain
  restoration remains visible in later disconnect reports. The editor coordinates
  COM ownership with logging and other ECU connections.

This is the normal v1.35.0 installation and retains existing release preferences,
installation paths and shortcuts.

## Install

Download **BMW_DDE5_MS43_Tuner_1.35.0_Setup.exe** and its matching `.sha256` file,
then run the installer. Setup downloads private Python and hash-verified runtime
libraries from python.org and PyPI. Internet is required. Installation is for the
current Windows user, with a Start menu shortcut, optional desktop shortcut and
uninstaller. System Python is unchanged. The installer is unsigned.

## Requirements and validation limits

The new RAM functions are specific to Bosch hardware **0281010565** and software
**1037361830 / 361830**. They require the reviewed installed MPC admission patch,
an original full 1 MiB FLS image matching the live blocks, and independently
verified external SRAM wiring, bank configuration and usable capacity. The editor
records the user's hardware declaration; it does not certify the hardware or
install an ECU patch.

Qualify on an engine-off bench with a fresh ECU boot, an idle manager and exclusive
diagnostic access. Live RAM actions remain connection-scoped and use 9600 baud,
8E1. The host enforces the declared 32 KiB or 64 KiB capacity; the stock firmware's
60 KiB arena is not proof of fitted memory. Whole-block additive checksums can
collide; exact readback is performed separately byte by byte. It is slow and does
not provide an atomic table snapshot.

Validation uses generated calibration data, simulated UART traffic, GUI checks
and original firmware instruction emulation. No physical ECU or SRAM arrangement
has yet validated this implementation. No flash erase/programming,
authentication or ECU-reset command is added. Save reports when restoration is
uncertain and follow their recorded recovery requirements.
